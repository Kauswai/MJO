# MJO

Windy.com plugin showing the Madden–Julian Oscillation: interactive RMM phase diagram,
current MJO position on the map and the GEFS 31-member ensemble forecast up to 7 days.

- Plugin + data pipeline: [windy-plugin-mjo/](windy-plugin-mjo/README.md)
- Daily data: <https://kauswai.github.io/MJO/mjo.json> (built by `.github/workflows/update-mjo-data.yml`)
